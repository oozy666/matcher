
Инструкция по запуску

Требования:
* Python 3.9+
* Зависимости: pandas, rapidfuzz

Установка зависимостей:
pip install pandas rapidfuzz

Запуск одной командой:
python main.py

Скрипт выполнит:
1. Оценку качества решения на data/labeled_sample.csv и вывод точности (Accuracy).
2. Обработку всех 300 записей из data/raw_positions.csv.
3. Сохранение итогового файла results.csv с колонками: id;исходное наименование;код;наименование по классификатору;уверенность;требует проверки да/нет.
